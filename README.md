# FoodWise
FoodWise is a full-stack food surplus management platform built to help reduce food waste and connect surplus food with organizations in need.

## Features

### Restaurant
- Track food prepared, sold, and remaining surplus
- Record surplus as donated, stored, discounted, given to staff, or wasted
- Manage food requests from organizations
- Track food rescued, waste, and overall impact

### Organization
- Browse available surplus food
- Request surplus food based on availability
- Track pending, approved, and rejected requests
- View received food and overall impact

## Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript

## Purpose

FoodWise helps restaurants manage surplus food efficiently while enabling organizations to access available food and reduce food waste.
